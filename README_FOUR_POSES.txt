วิธีใช้ไฟล์ชุดนี้
=================

ไฟล์ในนี้:
- Scenes/FourPoses.tscn   -> ฉากที่มีตัวละคร Doraemon (Rumba Dancing.fbx) 4 ตัว เรียงกัน แต่ละตัวเล่นท่าต่างกัน
- Scripts/CharacterPose.gd -> สคริปต์ที่ทำให้แต่ละตัวโหลดท่าและเล่น loop อัตโนมัติ

วิธีติดตั้ง:
1. คัดลอกโฟลเดอร์ Scenes กับ Scripts ในไฟล์นี้ ไปวางทับ (merge) ในโปรเจกต์ Godot ของคุณ
   (โปรเจกต์เดิมมีโฟลเดอร์ Scenes/ และ Scripts/ อยู่แล้ว วางรวมได้เลย ไม่ทับไฟล์เดิม)
2. เปิดโปรเจกต์ใน Godot แล้วเปิดไฟล์ Scenes/FourPoses.tscn
3. กด F6 (Run Current Scene) เพื่อรันฉากนี้ดูผลลัพธ์
4. จะเห็นตัวละคร 4 ตัวเรียงกัน: ยืน / เต้น / วิ่ง / เดิน พร้อมป้ายชื่อท่าลอยเหนือหัว และเล่นวนลูปตลอด

หมายเหตุสำคัญ:
- สคริปต์จะค้นหาชื่อท่าจาก Locomotion-Library.res และ Melee-Library--OLD.res
  โดยเทียบจากคำสำคัญ (idle, dance, run, walk ฯลฯ) แบบไม่สนตัวพิมพ์เล็ก-ใหญ่
- ถ้าตัวไหนไม่ขยับ (ค้างท่า T-pose) ให้เปิดแท็บ Output/Debugger ในโปรแกรม Godot
  จะมี Warning บอกว่า "หาไม่ท่าเจอ" พร้อม "รายชื่อท่าทั้งหมดที่มี" ให้เอาชื่อจริงจากตรงนั้น
  มาใส่ในช่อง Pose Keywords ของตัวละครตัวนั้นใน Inspector (คั่นด้วยเครื่องหมาย , ได้หลายคำ)
- ตัว "เต้น" ตั้งค่า use_default_library_as_fallback = true ไว้ เผื่อท่าเต้นเป็นแอนิเมชันที่ติดมากับ
  ไฟล์ Rumba Dancing.fbx เองอยู่แล้ว (ไม่ได้อยู่ในไลบรารีแยก)
- ถ้าอยากเปลี่ยนระยะห่างตัวละคร แก้ตัวเลขในบรรทัด transform ของแต่ละ Character_ ใน FourPoses.tscn
  (ตัวเลขสุดท้าย 3 ตัวคือตำแหน่ง x, y, z)
