วิธีใช้ไฟล์ชุดนี้ (Door + Trap)
================================

ไฟล์ในนี้:
- Scripts/Door.gd   -> สคริปต์ประตูไปด่านถัดไป (เช็คว่าเก็บไอเท็มครบหรือยัง)
- Scripts/Trap.gd   -> สคริปต์กับดัก (เด้งกลับจุดเกิด หรือจะให้หักไอเท็มด้วยก็ได้)
- Scenes/Door.tscn  -> ฉากประตูสำเร็จรูป มี Area3D + กล่องโปร่งใสสีเขียวให้เห็นตำแหน่ง
- Scenes/Trap.tscn  -> ฉากกับดักสำเร็จรูป มี Area3D + กล่องโปร่งใสสีแดงให้เห็นตำแหน่ง

วิธีติดตั้ง
-----------
1. ก๊อปโฟลเดอร์ Scripts/ และ Scenes/ ในไฟล์นี้ ไปทับ (วาง) ในโฟลเดอร์โปรเจกต์ Godot ของคุณ
   (คือโฟลเดอร์ 3d-platformer-kit/ ที่มี Scripts/ และ Scenes/ อยู่แล้ว)
   -> จะได้ไฟล์ใหม่ 4 ไฟล์เพิ่มเข้าไปโดยไม่ทับไฟล์เดิม
2. เปิดโปรเจกต์ใน Godot 4.7.2 ให้มัน re-import
3. เปิดฉากของคุณ (เช่น level_1.tscn) แล้วลาก Door.tscn และ Trap.tscn จาก FileSystem
   เข้ามาวางในฉากได้เลย เหมือนวาง Coin.tscn

การตั้งค่า Door (คลิกที่ node Door แล้วดู Inspector)
-----------------------------------------------------
- Required Items: ใส่จำนวนไอเท็มทั้งหมดที่มีในฉากนั้น (ต้องนับเองว่าฉากมีกี่เหรียญ)
- Next Scene Path: ใส่ path ของฉากถัดไป เช่น res://Scenes/level_2.tscn
  ถ้าเป็นด่านสุดท้าย จะปล่อยว่างไว้ก่อนก็ได้ (โค้ดจะแค่ print แจ้งเฉยๆ)

การตั้งค่า Trap (คลิกที่ node Trap แล้วดู Inspector)
-----------------------------------------------------
- Trap Mode:
    - reset_only          -> โดนแล้วแค่เด้งกลับจุดเกิด (เหมือน DeadZone เดิม)
    - reset_and_lose_item -> โดนแล้วเด้งกลับจุดเกิด + หักไอเท็มที่เก็บไปแล้ว 1 ชิ้น

ข้อควรระวัง (สำคัญ!)
--------------------
- ทั้ง Door.gd และ Trap.gd อ้างอิงถึง %SpawnPosition และ GameManager
  ซึ่งมีอยู่แล้วใน demo_scene.tscn ต้นฉบับ (Extras/SpawnPosition ตั้งเป็น Unique Name
  และ GameManager เป็น Autoload) ดังนั้นถ้าคุณก๊อปปี้ demo_scene.tscn ไปทำ level_1.tscn,
  level_2.tscn ต่อ มันจะมี SpawnPosition ติดไปด้วยอยู่แล้ว ใช้งานได้เลยไม่ต้องแก้อะไร
- แต่ถ้าคุณสร้างฉากใหม่จากศูนย์ (ไม่ได้ก๊อปจาก demo_scene) ต้องเพิ่ม Marker3D
  แล้วตั้งชื่อ Unique Name เป็น %SpawnPosition เอง ไม่งั้น Trap.gd จะ error ตอนรัน

- ปัจจุบัน Door/Trap เป็นแค่กล่องโปร่งใส (สีเขียว/แดง) ไว้ debug ตำแหน่งเท่านั้น
  แนะนำให้ไปหาโมเดลจริงจาก Poly Pizza (เช่น ประตู, หนาม, กองไฟ) มาวางเป็นลูกของ
  Door.tscn / Trap.tscn แทน MeshInstance3D กล่องสี แล้วซ่อนกล่องสี (visible = false) ทีหลังได้
